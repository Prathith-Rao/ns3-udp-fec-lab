# Repeated packet loss experiments

The user reported that all 12 deterministic integration scenarios passed in their
ns-3.45 WSL installation. The next step is to collect measured performance results.

## Run in the Ubuntu terminal

```bash
cd ~/ns3-work/ns-3.45
cp '/mnt/c/Users/Prathith Rao/Documents/Codex/2026-10-15/i-have-a-network-programming-course/outputs/run_experiments.py' run_experiments.py
sudo apt install -y python3-matplotlib
python3 run_experiments.py
```

This performs 250 short simulations: five configurations, five configured loss rates
and ten independent random runs per condition. It uses the existing udp-fec.cc.
The first executed simulation checks the build; later simulations skip rebuilding.

Configurations: plain UDP, adjacent packet duplication, and XOR protection with
groups of 2, 4 and 8 DATA packets. Configured independent loss: 0%, 1%, 5%, 10%, 20%.
Fixed settings: 1000 source packets, 160-byte payload, 20 ms source interval, 150 ms
playback deadline. All groups are complete, including k=8. Random loss affects both
DATA and PARITY packets on the last link; no deliberate drops are used here.

If interrupted, run the same command again to reuse completed simulations. A
manifest records the C++ source fingerprint and parameters to prevent mixing
different experiments. Changed settings require a new output directory, for example:

```bash
python3 run_experiments.py --repeats=20 --out=results/fec-campaign-20runs
```

## Experimental interpretation

The unit of replication for confidence intervals is a complete simulation run.
Each error bar is a two-sided 95% Student t interval using the ten run-level metric
values (nine degrees of freedom by default). The CDF is descriptive and conditional
on delivery; it is not a confidence interval. Link capacity is deliberately much
higher than offered load so random loss and redundancy can be isolated initially.

Application bytes include the 25-byte custom header and exclude UDP/IP/link headers.
Each mode carries the same original source payload and generation rate, but extra
transmissions increase offered traffic. Report this cost rather than treating the
redundancy as free. This campaign does not compare equal total bandwidth budgets.

For complete groups and independent per-transmission loss probability p, theoretical
eventual delivery probabilities are:

- Plain UDP: 1 - p.
- Duplication: 1 - p^2.
- XOR with k DATA packets and one PARITY packet: 1 - p + p(1-p)^k.

The XOR recovery term requires the chosen DATA packet to be lost, the other k-1
DATA packets to arrive and the PARITY packet to arrive. These predictions concern
eventual delivery. Deadline-aware performance must also account for parity arrival
time. For k=8, some missing early packets can be reconstructed after 150 ms even
when eventual recovery succeeds.

Use measured means and intervals in the report. Do not present theoretical values
as ns-3 results or claim actual audio quality was measured. Burst loss, interleaving
and alternative deadlines can be added after this campaign is reviewed.
